# Familie P — Regulated Advisory mit ProfessionalReviewGate (REG01–08)

Über dem geteilten Kern (family_a), strukturell wie andere Familien
(jede Aussage/Empfehlung braucht ihre Rechtsgrund-/Evidenz-/Norm-Naht;
Kern-Residuum einheitlich `unreviewed`). **Entscheidend:** diese
Domänen sind **PL4 ausdrücklich an das ProfessionalReviewGate gebunden**
(menschliche Fachprüfung/Berufszulassung). Der Agent hebt strukturell
NUR bis **PL3** (Adapter 11/11 + Zeugen + Kerntest) — ein grünes
Struktur-Gate ersetzt KEINE Berufszulassung (Masterplan §1, Anti-
Overclaim). PL4 bleibt sichtbar offen, review-gebunden.

| Domäne | Zweck | Kern-Naht | PL (Agent) | PL4-Bedingung |
|---|---|---|---|---|
| REG01 | Rechtsberatung | Rechtsgrund je Aussage | PL3 | ProfessionalReviewGate |
| REG02 | Medizinische Information | Evidenz je Aussage | PL3 | ProfessionalReviewGate |
| REG03 | Finanz-/Anlageberatung | Grundlage je Empfehlung | PL3 | ProfessionalReviewGate |
| REG04 | Steuerberatung | Norm je Aussage | PL3 | ProfessionalReviewGate |
| REG05 | Compliance-Gutachten | Norm je Befund | PL3 | ProfessionalReviewGate |
| REG06 | Ingenieur-Abnahme | Nachweis je Aussage | PL3 | ProfessionalReviewGate |
| REG07 | Gefahrgut-Bewertung | Maßnahme je Risiko | PL3 | ProfessionalReviewGate |
| REG08 | Klinische/Pharma-Doku | Regulatorik je Aussage | PL3 | ProfessionalReviewGate |

Beweis-Ort: `conformance/tests/family_p_catalog.rs`.
