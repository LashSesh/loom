# Familie J — Wissen/Forschung/Quellen (KNOW01–15)

Familie J nutzt DENSELBEN Kern wie Familie A (Text/Naht-Grammatik):
Einheit = Aussage/Quelle/Hypothese/…, Naht = Beleg-/Zitat-/Methoden-/
Fluss-Beziehung. Jede Domäne prüft ihre Kern-Naht fail-closed; bricht
sie, wird das genannte Kern-Residuum sichtbar. Alle auf PL3 (Adapter
11/11 · Zeugen · Kerntest · diese Doku-Zeile); PL4 verlangt echte
Nutzungs-/Review-Evidenz und bleibt offen.
